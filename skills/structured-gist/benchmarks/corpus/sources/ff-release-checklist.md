The release tag must match the version in the package metadata exactly. The changelog must contain an entry for the version being released. All CI checks on the release commit must be green, with no skipped required lanes. The release notes draft needs sign-off from the product owner. The staging environment must have run the release candidate for at least 24 hours. Database migrations in the release must be reversible or explicitly marked as one-way with an approved exception. The rollback plan must name the exact prior version and its deploy artifact. Customer-facing documentation changes ship before the release, not after. The on-call engineer for release week must be named in the release ticket. Feature flags for new functionality default to off in production. The security scan report must be attached to the release ticket and show no critical findings. Announcements go out only after the last region reports healthy.
