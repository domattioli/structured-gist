It wraps a large language model and adds the ability to act by giving it tool execution, a control loop, memory, and guardrails. The control loop repeatedly assembles context (system prompt, chat history, tool schemas), lets the model emit tool calls, has the harness execute those calls with real side effects on files/shell/network, feeds the results back to the model so it can reason over fresh evidence, and repeats until the task is done or a budget cap is hit. Guardrails include sandboxing and permission gates, where irreversible operations pause for human confirmation.
