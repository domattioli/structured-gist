Branch names use the pattern type slash short-description, where type is one of fix, feat, docs, chore, refactor, or test. Commit messages start with the same type word followed by a colon and an imperative summary. Pull requests stay under 400 changed lines unless the change is a mechanical rename. Every pull request gets one approving review before merge, two if it touches the billing module. The main branch deploys automatically on merge. Force pushes to shared branches are forbidden. Meetings live on Tuesdays and Thursdays only, and Wednesdays are meeting-free by team agreement. Standup is written, posted in the team channel before 10:30 local time. Decisions that outlive a sprint get an entry in the decision log the same week. Interface changes between services require a design note circulated 48 hours before implementation starts. On-call handover happens Mondays at 09:00 with a written summary of open incidents. The style linter's verdict is final and style debates in review are out of bounds.
