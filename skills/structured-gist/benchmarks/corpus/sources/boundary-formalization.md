The first library is responsible for generating a triangular mesh from a 2D domain description, faithfully porting a set of locked numerical stages that must stay bit-identical to a reference MATLAB implementation. The second library takes that generated mesh as input and provides a general-purpose data structure plus smoothing and quality-analysis operations on top of it, including converting triangles to quadrilaterals. The two libraries are meant to compose, with the first library's output format designed to round-trip cleanly into the second library's loader.
