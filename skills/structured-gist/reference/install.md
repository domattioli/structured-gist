# Install

Install structured-gist from the Claude Code marketplace:

```
claude plugin install structured-gist@claude-ai
```

After installation, invoke the skill with:

```
/structured-gist [level] [mode]
```

Where:
- `level`: one of `skim` (default), `standard`, `deep`
- `mode`: one of `block` (default), `responsive`

See `SKILL.md` for the complete rule set and render-mode details.
